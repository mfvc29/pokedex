# Pokédex Multijuego

Pokédex en español pensada para el celular, con selector de juego:
Esmeralda, Rojo Fuego, Verde Hoja, Oro HeartGold, Plata SoulSilver, Platino, Negro, Blanco, Negro 2, Blanco 2, X, Y, Rubí Omega, Zafiro Alfa, Ultrasol, Ultraluna, Let's Go Pikachu, Espada, Leyendas Arceus, Escarlata y Leyendas Z-A.

- Pokédex regional de cada juego (con DLC donde aplica) y buscador por nombre o número.
- Evolución con el método correcto para ese juego.
- Dónde encontrar cada Pokémon en ese juego, con nivel y probabilidad cuando hay datos.
- Debilidades según la generación (sin tipo Hada antes de X/Y).
- Concursos (Esmeralda, Rubí Omega, Zafiro Alfa, Platino): bayas para pokécubos/pokochos y lista de cintas para marcar.
- Se instala como app y funciona sin conexión después de la primera visita.

Página estática: `index.html`, datos en `core.json`, `berries.json` y `g/<juego>.json`, imágenes en `s/`.

Datos: PokéAPI, Bulbapedia y los textos de ubicaciones de PKHeX. Pokémon es una marca de Nintendo, Creatures y GAME FREAK; proyecto de fans sin fines comerciales.
